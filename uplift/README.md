# S2 · Uplift 干预效果建模（模拟环境里的反事实学习）

> **边界一句话**：L2 回答「这个人是什么样的人」，L3 回答「他现在该不该干预」，S1 回答「干预下去会发生什么」，**S2 回答「只有观测数据时，能把干预效果学多准、触达名额花给谁最值」**。
>
> 为什么需要它：S1 手里有完整反事实，那是"上帝视角"；现实里一个用户只会被触达一次、只能观测到一条世界线。S2 故意把上帝视角"降维"成两种训练数据（rct / full），跑同一套模型与评测——差距就是**反事实不可观测的代价**；留出集真值只用来判分，模型永远看不见。
>
> 所以这一层 **不做**：业务结论（那是 L3 / harness 的判断）、动作排序与在线学习（S3 Bandit）、真实世界因果断言（模拟器只保证"方法可验证"，不保证"数字可迁移"）。

**本层决策（2026-10-05，已定稿）**
- 双协议：**rct**（每人随机分 1 臂、只观测该臂 = 现实口径）/ **full**（三臂全可见 = 理论上限参照）。
- 模型：**T-learner**——每臂一个结果模型，`τ̂ = f_arm − f_control`；**HistGBM 主 + Ridge 线性基线**。
- 评测三层：**保真度 / 分位校准 / 策略价值曲线**（对照 random 与两条 oracle）。

## 1. 数据流与模块

```
simulator.build_tables(...)        （S1，纯内存：真值 CATE 表）
        │  训练帧降维：只保留 uid / arm / y / 四件可观测状态
        ▼
uplift/
        ├── protocol.py    切分 / RCT 分配 / 观测标签（rct 与 full 两条口径）
        ├── models.py      T-learner（HistGBM 主 + Ridge 基线）
        ├── evaluate.py    保真度 / 分位校准 / 策略价值曲线（模型 vs oracle）
        ├── run_uplift.py  CLI：全流程、落盘、_manifest.json、双跑一致性校验
        └── tests.py       冒烟与一致性测试（协议 / 无泄漏 / 端点 / 信号 / 边界）
        ▼
data/synthetic/uplift/             （合成数据，gitignored；可随时按种子重生成）
    ├── uplift_metrics.json        配置 / 保真度汇总 / 参考 k 下的策略价值
    ├── uplift_calibration.csv     按 τ̂ 十等分的校准表
    ├── uplift_policy.csv          策略价值曲线（k% × 策略 × 臂）
    ├── uplift_holdout.csv         留出集逐行评测帧（τ̂ / 真值 / 观测净奖励）
    └── _manifest.json             版本 / 模拟参数快照 / 模型超参 / 输出指纹 / 双跑一致
```

**硬规则（反循环论证，四条都是被测过的）**
1. **特征白名单只有四件可观测状态**（`act_30d / silence_days / interest_concentration / tenure_days`）；真值列（`tau_*`、`increment`、`reward`、`cost`、`a_daily`）一律不进训练帧——tests 断言列集合，并验证**模型对白名单外的列不敏感**。
2. **按用户切分**（默认 70% / 30%）：同一用户不会同时出现在训练与留出；拟合只吃训练集的观测标签 `y`，留出集真值只用于判分。
3. **deterministic**：同参同种子逐字节一致；CLI 默认**双跑一致性校验**，不一致拒绝落盘。
4. 产出是**合成环境上的方法验证**，不是真实世界的因果结论。

## 2. 两种训练协议（同一套模型的两种现实假设）

| 协议 | 训练观测 | 行数 | 现实含义 |
|---|---|---|---|
| `rct` | 每人**随机均匀分 1 条臂**，只观测该臂结果：对照看 `y_void_window`，触达看 `y_treated_window` | = 训练用户数 | 现实中**可执行**的标准做法（随机对照） |
| `full` | 每人 **3 行**：对照用 `y_void`，两条触达臂各用 `y_treated` | = 3 × 训练用户数 | 现实中**不存在**（反事实全知）——理论上限参照 |

留出集 = 每用户 × 每臂的评测帧（含真值 `tau_struct / tau_ind / increment / cost / reward`），只用于判分。
两条协议用**同一个种子、同一份人口、同一套模型与评测**各跑一遍，差距即"反事实不可观测的代价"。

## 3. 模型与评测口径

**T-learner**（每臂一个结果模型）：`τ̂(u, arm) = f_arm(x) − f_control(x)`，对照臂恒 0；模型输入只取四件可观测状态。

| 学习器 | 超参（设计取值） | 角色 |
|---|---|---|
| `hgb` | `max_iter 400 · lr 0.05 · max_depth 3 · min_samples_leaf 30 · l2 1.0 · early_stopping False` | 主力：能学非线性与交互（召回的钟形、推荐的门槛） |
| `ridge` | `StandardScaler + Ridge(alpha=1.0)` | 低方差基线：对照"树模型到底带来了什么" |

**评测三层**
1. **保真度**（每臂每学习器）：`bias = mean τ̂ − mean tau_struct`、Pearson / Spearman（vs `tau_struct`）、Spearman（vs `tau_ind`）、MSE / MAE。
2. **分位校准**：按 τ̂ 十等分，每档对比 `mean τ̂` 与两种真值均值——排序对了但整体放大 / 缩小会在这里现形。
3. **策略价值曲线**：按各策略得分取前 k% 用户触达，`value = mean(increment − cost)`。
   - `random`（不排序，解析期望 = 该臂全体均值，各 k 相同）／`oracle_struct`（按 `tau_struct` 排序 = 给定可观测状态的最优排名）／`oracle_ind`（按 `tau_ind` 排序，含不可观测个体噪声）／`model_*`（按 τ̂ 排序）。
   - **k=100% 时所有策略取全体，value 必然相等**——tests 锁死该端点。

## 4. 结果（离线默认人口，6000 人 × 14 天，seed 11）

先说一句背景：默认人口是**沉默为主**的社区（`act_30d>0` 约 12.7%），召回的用武之地天然更大。

**保真度（留出 1800 人 × 每臂）**

| 协议 | 臂 | 学习器 | mean τ̂ | mean τ_struct | bias | Spearman(τs) | Spearman(τi) |
|---|---|---|---|---|---|---|---|
| rct | rec | hgb | 0.132 | 0.144 | −0.012 | 0.427 | 0.426 |
| rct | rec | ridge | 0.165 | 0.144 | +0.021 | 0.546 | 0.546 |
| rct | recall | hgb | 1.981 | 1.975 | +0.007 | **0.868** | 0.758 |
| rct | recall | ridge | 1.964 | 1.975 | −0.010 | 0.911 | 0.802 |
| full | recall | hgb | 1.938 | 1.975 | −0.036 | **0.926** | 0.817 |
| full | rec | hgb | 0.145 | 0.144 | +0.001 | 0.538 | 0.538 |

**策略价值（留出集，k=20%，单位 = 事件当量）**

| 协议 · 臂 | random | model_hgb | model_ridge | oracle_struct | oracle_ind |
|---|---|---|---|---|---|
| rct · recall | +0.947 | **+2.186** | +1.944 | +2.303 | +2.764 |
| full · recall | +0.947 | +2.247 | +1.908 | +2.303 | +2.764 |
| rct · rec | −0.368 | +0.047 | +0.142 | +0.161 | +0.161 |
| full · rec | −0.368 | +0.150 | +0.161 | +0.161 | +0.161 |

**读出来的四件事**
1. **价值所在的那条臂，学得很准**：召回臂 rct 口径 Spearman 0.87（full 0.93），平均偏差 ≤ 0.04 事件；定向触达 k=20% 净收益 **+2.19**，而不排序只有 +0.95——**模型把名额花对了地方**。
2. **反事实全知值多少钱**：full 全面优于 rct，推荐臂最明显（Spearman 0.43 → 0.54，偏差从 −0.012 → +0.001）。这就是「同一用户只能观测一条世界线」的代价——在效应弱的臂上尤其贵。
3. **rec 臂在默认人口里几乎不可行**（数据结论，不是模型问题）：不排序 −0.368；即便按 oracle 结构排名取前 20%，也只有 +0.161 < 成本压力——推荐臂的效应量级撑不起 0.5 的成本。这正是"在沉默为主的社区里，无差别推内容不如精准召回"的模型版回声。
4. **个体噪声的残余价值**：`oracle_ind`（+2.764）> `oracle_struct`（+2.303）——知道每个用户的个体噪声还能多赚 0.46，但 ν 不在特征里，**不可学**；模型贴着结构上限（+2.19 vs +2.30）已是 rct 口径下的合理落点。

## 5. 运行与产出

```bash
# 在仓库根目录执行
python -m uplift.run_uplift --users 6000 --seed 11        # 默认：有 L2 用拟合人口 + 双跑校验
python -m uplift.run_uplift --no-fit --users 6000         # 强制默认人口（离线可复现路径）
python -m uplift.run_uplift --protocol rct --no-verify    # 只跑 rct、跳过校验（快路径）
python -m uplift.tests                                    # 测试（也可 pytest uplift/tests.py）
```

CLI：`--users --days --window --seed --holdout --protocol both|rct|full --learners --ks --out --features --no-fit --no-verify`。
退出码：参数无效 `2`；双跑不一致 `3`（拒绝落盘）。

产出（默认 `data/synthetic/uplift/`，不入公开仓）：见 §1 文件清单；`_manifest.json` 冻结版本 / 模拟参数快照 / 模型超参 / 输出指纹与行数。

## 7. 已知局限（诚实清单）

1. **无真实标签**：真值来自模拟器——价值在"方法验证"（协议对照、无泄漏、可复现），不在"业务数字"。
2. **协议即假设**：rct 假设完全随机分配、无干扰；真实平台存在选择偏差与曝光机制，v0 未建模。
3. **rec 臂结论依赖人口**：换人口（fit 路径 / 真实扩采后的分布）数字会变；成本口径改变也会变。
4. **单次触达**：S1 v0 每人每臂只触达一次，不含重复触达的疲劳序列；S3 v0 沿用批量口径（未启用日粒度迭代），疲劳序列留给后续版本。
5. **模型族有限**：只有 HGB / Ridge，未做超参搜索与交叉拟合（cross-fitting）——v1 候选。
6. **oracle 只在留出集内排序**：小 k 下方差可见（本仓 1800 留出用户下已稳定）。
