诚实边界（随结论一起引用）

  • 样本：200 人 pilot，来自"近期有公开活动"的用户 → 结论不代表全站；迁移仅 21 人可判定。
  • 标签：单快照、无纵向回访 → 流失档是「observed_inactivity」（公开活动沉默代理），不是平台真实流失；阈值 calibration_status = uncalibrated。
  • 行为痕 ≠ 埋点：只有评论 / 评分 / 收藏 / 关注 / 时间戳等公开痕迹；不含曝光、停留、支付等内部数据。
  • 时间线：time_kind=unknown 的事件不参与任何时间序列与迁移计算。
  • 模拟轨是方法验证：数字（召回净奖励、80.4%、78.8% 等）来自合成世界，不迁移到真实业务；各模块种子不同（S1 seed 7 / S2 seed 11 / S3–S4 seed 13），按各自口径展示。
  • 抽样波动：S3 审计池 1,800 人冻结评测，末位数字有抽样波动（学习信号已跨种子复核）。
  • 合规：只采集公开可见信息；限速，403/429 即停，不重试、不绕过权限；ip_location / device / gender 等只在聚合层出现；关注 / 粉丝的对方 id 只出计数。
