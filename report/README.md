# S5 · 展示层（静态自包含 HTML 报告）

> **边界一句话**：S1–S4 的产出此前散落在多份落盘文件里，**S5 把它们汇总成一张离线可开的 HTML 报告**——真实轨（L1–L3）讲"用户现在什么状态"，模拟轨（S1–S4）讲"干预下去会发生什么"，关键数字、图表与诚实边界同页呈现。
>
> 为什么需要它：端到端项目需要一个**不依赖运行环境**的交付面——配好本地数据后跑一条命令，就能拿到逐字节可复现的报告；报告本身只含聚合数字，不含任何逐用户隐私数据。
>
> 所以这一层 **不做**：重跑任何模型（只读已落盘产出）、交互式图表（无 JS）、逐用户明细（隐私红线）。

**本层决策（2026-10-05，已定稿）**
- **形态：静态自包含 HTML**——零依赖、零 CDN、离线直开；图表全部是 Python 生成的 inline SVG（无 `xmlns`、无脚本）；页面**不含时间戳**（逐字节可复现，时间只进 `_manifest.json`）。
- **数据来源：复用已落盘产出聚合**——只读各模块 `_manifest / metrics / summary / curve / trace`，不重跑模型。
- **范围：S1–S4 模拟轨 + 真实轨 L1–L3 聚合**——真实轨产出缺失时自动跳过该章节（报告仍可生成）。

## 1. 数据流与模块

```
data/synthetic/（S1–S4 合成轨产出，必需 7 份）
data/processed/（L2 / L3 manifest，可选；data/raw 仅数文件个数）
        │  collect()：只读聚合 → stats（统计值）+ sources（每份输入的 sha256 16 位 / 行数）
        ▼
report/
        ├── build_report.py  collect → inline SVG 渲染 → index.html + _manifest.json
        └── tests.py         双跑 / 自包含 / 数字对源 / 缺轨跳过 / 隐私扫描
        ▼
report/index.html         （提交进仓：离线直开；仅聚合数字，无逐用户隐私数据）
report/_manifest.json     （版本 / 输入指纹 / 输出指纹 / 双跑一致）
```

**硬规则（都被 tests 测过）**
1. **只读产出、不重跑模型**：报告是一次纯函数渲染——同输入双跑 HTML 逐字节一致；篡改输入统计后 HTML 必须变化（防"读缓存/常量"）。
2. **页面自包含**：无 `<script>`、无 `http(s)`、无 `src=` 外部资源；相对链接只指向同仓模块 README。
3. **无时间戳**：HTML 内不含任何时间信息（含 `generated_at`），保证产出可逐字节校验；时间只写进 `_manifest.json`。
4. **隐私红线**：全页只有聚合数字；tests 内置扫描（盘符绝对路径 / `uid_hash` / `h_` 用户哈希名 / `ev_` 事件哈希 id 一律不得出现）。
5. **缺轨降级**：合成轨缺失 → 退出码 4 + 重跑指引（拒绝生成）；真实轨缺失 → 自动跳过该章节。
6. **deterministic**：CLI 默认双跑一致性校验，不一致拒绝落盘（退出码 3）。

## 3. 运行与产出

```bash
# 在仓库根目录执行
python -m report.build_report              # 生成 report/index.html + _manifest.json（含双跑校验）
python -m report.build_report --no-verify  # 跳过双跑校验（快路径）
python -m report.tests                     # 测试（也可 pytest report/tests.py）
```

退出码：参数无效 `2`；双跑不一致 `3`（拒绝落盘）；合成轨输入缺失 `4`（附按序重跑指引）。

`_manifest.json` 冻结：报告版本 / 生成时间 / 输入指纹 / 每份输入的 `sha256` 与行数 / 章节清单 / 关键数字（highlights）/ `index.html` 的字节数与 `sha256` / 双跑一致结论。

## 6. 已知局限（诚实清单）

1. **只读快照**：报告反映生成时刻的落盘产出；重跑 L1–L3 或 S1–S4 后需重新生成（指纹会变，跨批可比）。
2. **无交互**：静态 SVG 折线 / 柱图，不支持 hover / 缩放（换取零依赖与逐字节可复现）。
3. **真实轨是可选章节**：公开仓不含真实数据，clone 后不配本地数据只能看到模拟轨 7 节。
4. **数字按各模块口径原样展示**：各模块种子不同（S1 seed 7 / S2 seed 11 / S3–S4 seed 13），不做统一，也不重算。
5. **摘要非全量**：每节只呈现代表性数字与图表；完整口径见各模块 README。
