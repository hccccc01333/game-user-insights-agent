# ML 沉默预测 · 可行性快检记录（2026-10-06）

> 目的（P0 前置）：在正式开工「ML 沉默预测」前，用现有数据回答三个问题——
> ① 样本量够不够；② 正负例是否均衡、特征是否可得；③ 能否支撑"显著优于现有
> heuristic（recency 阈值）"的评估。
>
> 本记录基于 **200 人 pilot** 时间线（扩采 270→400 进行中；批次完成后复核更新）。

## 1. 数据与面板口径

输入（均为本地产物，不入公开仓）：

- `data/processed/user_features/timeline.jsonl`：9,521 个公开时间戳事件（仅
  `time_kind=exact` 参与；`unknown` 事件不进任何时间序列）；
- `data/raw/user_profile/_index.jsonl`：每用户采集时刻 `fetched_at`（右截断保护）。

面板构造（(用户, 锚点 T) 样本）：

- 锚点 T 从该用户**首个可见事件 + 30 天**起、以 30 天步长推进；
- 样本条件：用户在 (T−30d, T] 内有活动（对应"对近期活跃用户问：他会不会静默"）；
- 右截断保护：`T + h ≤ 采集时刻`（标签窗口必须完整落在观测期内）；
- 标签：`y_h = 1` 表示 (T, T+h] 内无任何公开事件（沉默）；h ∈ {7,14,30,60,90} 天；
- 左截断标记：T−180d 早于首个可见事件时，180 天窗口不完整（82% 锚点完整）。

## 2. 结果

### 2.1 规模与标签

- 样本 1,630（h=30 口径）；200 人全部贡献（中位 6 条/人，最多 62 条）。
- 沉默率：h=7 → 84.0%｜h=14 → 74.1%｜h=30 → 61.2%｜h=60 → 45.9%｜h=90 → 36.6%。
  **h=30 正负均衡，定为主视界**。

### 2.2 判别力（全特征 = 6 窗计数 n7..n180 + gap；对照 = 仅 gap）

评估：GroupKFold(5 折，按 uid 分组，防同类泄漏) + LogisticRegression(class_weight=balanced)。

| 视界 | 样本 | 同期 AUC | 仅 gap | 时间外推（训 ≤2025 → 测 2026） |
|---|---|---|---|---|
| 7d | 1681 | 0.692 | 0.627 | 0.636 vs 0.607 |
| 14d | 1669 | 0.685 | 0.603 | 0.659 vs 0.582 |
| 30d | 1630 | 0.704 | 0.609 | **0.697 vs 0.623** |
| 60d | 1527 | 0.692 | 0.597 | 0.694 vs 0.602 |
| 90d | 1373 | 0.680 | 0.584 | 0.689 vs 0.590 |

### 2.3 特征窗口的贡献（y_30）

| 特征集 | 同期 AUC |
|---|---|
| n30+gap | 0.623 |
| n7+n14+n30+gap | 0.622 |
| **n90+n180+gap** | **0.702** |
| 全部 6 窗 + gap | 0.704 |

- **长窗（90/180 天）是信号主力**；短窗独立增量 ≈0。
- 稳定性检查：仅取 180 天窗口完整的 82% 锚点，结果不变（同期 0.706 / 外推 0.700）
  —— 非左截断假象。

### 2.4 结构类特征增量（在长窗主干之上）

| 增量块 | 同期 ΔAUC |
|---|---|
| B1 类型结构（180d 类型占比） | +0.006 |
| B2 评分序列（均值 / 负评 / 趋势） | ≈0 |
| B3 品类迁移（app 标签 Jaccard 等） | ≈0 |
| B4 关注面（follow 计数） | +0.003 |
| 全部叠加 | ≈0（外推还略降） |

原因：用户事件稀疏——51.7% 锚点 180 天内无评分、83.3% 锚点双窗无 app 标签。
**结构类特征暂缓**，等更长观察历史后再验证。

### 2.5 结论修正记录

初版特征仅含 ≤60 天窗口 → 曾得出"时间外推无优势"（0.616 vs 0.623）。
加入 90/180 长窗后外推优势恢复（0.702 主干：外推 0.698 vs 0.623）——
**"外推劣势"是特征过短的假象**。教训：验证"能否优于 recency"必须在
长窗特征集上做，否则会低估可行空间。

## 3. 口径风险（结论须随附引用）

- **幸存者偏差**：种子 = 近期评价作者，样本偏向仍活跃用户；沉默率为"此类用户"口径。
- **左截断**：可见历史 ≠ 完整历史（分页可见范围）；已用完整窗口子集验证稳健。
- **样本自相关**：相邻锚点共享预窗；已用按用户分组 + 时间外推双重评估对冲。
- **h=7 的沉默是节律常态**：近 7 天有活动的用户下周仍 75.3% 沉默——h=7 只适合
  "下周回访预测"口径，运营干预建议 h ≥ 14/30。

## 4. 决策与下一步

- **可行**：样本量非瓶颈（400 人预计 ~3,200 样本）；判别力上界已看到
  时间外推 +0.07～0.10（vs recency）。
- **M1 达标线**：时间外推（训旧 → 测新）AUC **显著** > recency 基线；
  不看训练集 / 同期拆分 AUC。
- **特征集**：多窗计数主干（以 90/180 天为主）+ 类型占比（可选）；不做复杂特征工程。
- 下一步：400 人批次完成后 → 重跑 L2 时间线 → 面板复核 → 正式可行性报告。
