# S1 · 用户模拟器（干预实验沙盒 · 真值 CATE）

> **边界一句话**：L2 回答「这个人是什么样的人」，L3 回答「他现在该不该干预」，**S1 回答「干预下去会发生什么」**——它是合成世界里的对照实验台。
>
> 为什么需要它：真实平台不可能让同一个用户同时「推」和「不推」，没有反事实就没有因果。模拟器把两份世界都跑出来——**每个用户 × 每条臂**都有一行真值（结构 CATE / 个体 CATE / 实现增量 / 净奖励），下游 Uplift 与 Bandit 的靶子由此而来。
>
> 所以这一层 **不做**：业务结论、人群命名、策略文案——那些是 L3 / harness（Agent）的判断；S1 只产"实验数据 + 真值"。

**本层决策（2026-10-05，已定稿）**
- 三臂：**对照 / 个性化内容推荐 / 沉默用户召回提醒**。
- 奖励：**未来 7 天活跃增量 − 触达成本**（连续值，事件当量）。
- 效应：**按用户状态异质**（近 30 天活跃度、沉默时长、兴趣集中度、资历）**+ 疲劳衰减 + 个体噪声**；模拟器持有真实 CATE。

## 1. 数据流与模块

```
data/processed/user_features/features.csv      （本地 L2 产物，只读；不入公开仓）
        │  拟合路径：读四列的分位形状（act_30d / recency_days / genre_top1_ratio / tenure_days）
        ▼
simulator/
        ├── params.py          参数与口径单一真源（证据分级见 §6）
        ├── user_generator.py  合成人口：分位数秩耦合拟合 + 内置默认分布兜底
        ├── response.py        效应模型：三臂真实 CATE（纯函数）
        ├── env.py             日步长环境：配对 rollout（共同随机数 CRN）
        ├── reward.py          奖励契约：窗内增量 − 触达成本
        ├── run_sim.py         CLI：跑实验、落盘、写 _manifest.json、双跑一致性校验
        └── tests.py           冒烟与一致性测试（确定性 / 校准 / 边界 / 单调性）
        ▼
data/synthetic/                （合成数据，gitignored；可随时按种子重生成）
    ├── sim_users.csv          每个合成用户的初始状态
    ├── sim_effects.csv        ★ 用户 × 臂：真值 CATE 与净奖励
    ├── sim_daily.csv          天 × 臂 人口聚合（看效应衰减与基线）
    └── _manifest.json         版本 / 种子 / 参数快照 / 人口口径 / 输出指纹 / 双跑一致
```

**硬规则**
1. **产出全部为合成数据**：uid 一律 `sim_` 前缀，与真实 `uid_hash` 永不混淆；拟合路径只读取"分布形状"（分位数），不复制任何一条真实用户记录。
2. **deterministic + versioned + replayable**：同种子 + 同参 + 同版本 → 逐字节一致；换口径 = 升 `SIM_VERSION` + 重跑；`run_sim` 默认做**双跑一致性校验**，不一致拒绝落盘。
3. **证据分级**：每个参数标注 校准值 / 设计取值 / 派生值（§6），不把设计值伪装成校准值。

## 2. 三臂与奖励口径

| 臂 | 名称 | 触达成本（事件当量） | 效应机制（一句话） |
|---|---|---|---|
| `control` | 对照（不触达） | 0 | 无效应；提供反事实基线 |
| `rec` | 个性化内容推荐 | 0.5 | 对**有清晰兴趣且近期活跃**的人有的放矢 |
| `recall` | 沉默用户召回提醒 | 1.0 | 对**沉默 1–3 个月**的人最可能唤回 |

```
reward(u, arm) = increment_7d(u, arm) − cost(arm)
increment_7d   = Σ 触达轨迹前 7 天事件 − Σ 未触达轨迹前 7 天事件   （同一用户、配对）
```

- 单位：**事件当量**（1 ≈ 一条公开互动行为）；奖励可正可负（对照臂恒 0）。
- 成本是**设计取值**（无公开数据可校准），改 [params.py](params.py) 的 `cost_events` 全链路生效。
- 只计 7 天窗内事件；窗外只在 `sim_daily.csv` 做衰减诊断，不计奖励。

## 3. 用户生成（合成人口）

每个合成用户 = **四件可观测状态 + 一件潜在节奏**：

| 字段 | 含义 | 用途 |
|---|---|---|
| `act_30d` | 近 30 天事件数 | 效应异质性输入（推荐的门槛） |
| `silence_days` | 沉默时长（天） | 效应异质性输入（召回的钟形） |
| `interest_concentration` | 兴趣集中度 ∈ [0,1] | 效应异质性输入（推荐的准度） |
| `tenure_days` | 账号资历（天） | 效应异质性输入（召回的折减） |
| `a_daily` | 潜在日活跃概率 | 驱动 rollout 的节奏参数（唯一行为源） |

**两条路径（互为兜底）**
- `fit`：本地存在 L2 特征表时，对四列做**分位数秩耦合抽样**——`act_30d` 与 `silence_days` 共用同一分位秩（保留"越活跃越不沉默"的单调负相关），集中度与资历用独立秩；`act_30d>0` 的节奏由事件数反推 `a ≈ act_30d / (30 × 活跃日平均条数)`，`act_30d=0` 的用户落在很低但非零的"偶发冒泡"节奏带。
- `default`：无本地数据（公开仓离线场景）用内置默认分布，保证不依赖任何数据文件即可完整跑通：

| 档位 | 占比 | act_30d | a_daily | 沉默天数 |
|---|---|---|---|---|
| dormant | 55% | 0 | 0.001–0.004 | 60–720 |
| silent | 33% | 0 | 0.004–0.020 | 35–150 |
| low | 9% | 1–6 | 0.025–0.140 | 7–70 |
| active | 3% | 6–60 | 0.140–0.550 | 0.5–21 |

（默认分布为设计取值；口径对齐说明：档位占比使 `act_30d>0 ≈ 11–12%`，与已发表口径"约 11.5%"衔接。沉默分布取更宽的先验，不逐点复刻本地观测形状。）

**诚实标注（v0 近似）**：逐列边缘分布对齐 + 秩耦合，**不是完整联合分布拟合**；`silence_days` 与节奏的一致性由秩耦合近似——这是 v0 的已知简化。

## 4. 效应模型（真实 CATE 的来源）

τ = 奖励窗内活跃增量期望（单位：事件）。`x` = 上述四件可观测状态。

```
个性化内容推荐   τ_rec = A_rec · c_eff · g(r) · f(s)
    c_eff = clip(c / 0.12, 0.2, 1.2)          兴趣越集中，推荐越有的放矢
    g(r)  = sqrt(clip(r / 6, 0, 1))           近 30 天越活跃响应越强（次线性；r=0 严格为零
                                              ——对完全沉默者不做内容推荐，那是召回臂的活）
    f(s)  = exp(−s / 60)                      沉默越久越难唤起

沉默用户召回     τ_recall = A_recall · hump(s) · t(T)
    hump(s) = exp(−(ln(s/90))² / (2·1.2²))    对数钟形：90 天上下最可召回；刚活跃过的与之
                                              久沉默（>1.5 年）的两端衰减
    t(T)    = clip(1500 / (T + 250), 0.4, 1.25)   资历折减：新账号更易召回

个体效应         τ_i = τ(x) · exp(ν − σ²/2)，ν ~ N(0, 0.35²)
```

- **疲劳**：同一臂第 n 次触达乘 `ρ^(n−1)`（ρ=0.5）——第二次触达效应减半，第三次再减半。
- **噪声**：对数正态乘性噪声，中位数 ≈ 结构值、期望仍为结构值；σ=0 时全体同质（测试可验证）。
- **单调性由 tests.py 验收**：召回的钟形（90 天最强、两端衰减）、推荐对集中度/活跃度的单调递增、对沉默时长的递减、对照臂恒 0。
- 效应折算到日粒度：窗口内权重 ∝ `0.7^d` 并归一（当天的效应 ≈ 33%），再除以活跃日平均条数换算成"活跃概率增量"（封顶保证概率 ≤ 0.98）。

## 5. 配对 rollout（共同随机数 CRN）

- 每个用户两条独立随机流（行为流 / 响应噪声流），由 `SeedSequence([seed, 流号, 用户下标])` 派生：**同种子同用户永远同轨迹**；在人口末尾追加用户不会扰动已有用户。
- 同一用户的"触达 / 不触达"两条轨迹**共用同一串随机数**，且每天固定消耗 3 个随机数（无论是否活跃）——增量里只剩干预本身造成的差异，运气被配对消掉。
- 由此得到一条硬性质：所有臂的增量 **≥ 0**（配对下触达只可能把"不活跃日"翻成"活跃日"）；对照臂增量**恒等于 0**。

## 6. 参数表（证据分级）

| 参数 | 取值 | 分级 | 来源 / 说明 |
|---|---|---|---|
| 活跃日恰 1 条占比 `count_p1` | 0.76 | **校准** | calibration/reddit_params.csv（Reddit gaming 日评论形态） |
| 尾部几何 `count_tail_p` | 0.36 | 设计 | 使 p90=3、p99=9 对齐锚点（尾部从 2 起） |
| 活跃日平均条数 `count_mean_active` | 1.667 | 派生 | `p1·1 + (1−p1)·(2+E[Geom])` |
| 奖励窗口 | 7 天 | 设计 | 与社区周留存锚点同尺度 |
| 触达成本 | 0 / 0.5 / 1.0 | 设计 | 事件当量；唯一约束是"召回（1.0）比推荐（0.5）贵" |
| 推荐强度 `A_rec` | 2.5 | 设计 | 量级参照：单次触达周增量 ≈ 一天活跃产出 |
| 召回峰值强度 `A_recall` | 3.0 | 设计 | 同上 |
| 召回峰值 `recall_peak_days` | 90 天 | 设计 | 与"沉默中位约 81 天"的群体形态衔接 |
| 日衰减 `effect_daily_decay` | 0.7 | 设计 | 效应在窗内前重后轻 |
| 个体噪声 σ | 0.35 | 设计 | 对数正态乘性；是任何模型的不可约误差参照 |
| 疲劳 ρ | 0.5 | 设计 | 同臂重复触达逐次减半 |
| 默认人口混合 | 见表 §3 | 设计 | 仅离线路径使用 |
| 情感 / 浏览深度类信号 | — | 不适用 | 与 calibration 项一致：不可观测，不伪装为校准值 |

**口径对照（模拟器 vs 已发表锚点）**：恰 1 条 76%（校准命中，`run_sim` 每次自检打印）；p90=3 / p99=9（设计命中）；`act_30d>0 ≈ 11%`（fit 路径对齐）。**未对齐项**：周留存分层（21.4% / 14% / 29.1% / 54.4%）v0 未模拟——列为局限，v1 候选。

## 7. 运行与产出

```bash
# 在仓库根目录执行
python -m simulator.run_sim --users 500 --days 14 --seed 7        # 默认：有 L2 就用拟合路径
python -m simulator.run_sim --no-fit --users 800                  # 强制默认分布（离线可复现路径）
python -m simulator.tests                                        # 测试（也可 pytest simulator/tests.py）
```

CLI：`--users --days --window --seed --out --features --no-fit --no-verify`。

产出（默认 `data/synthetic/`，不入公开仓）：

| 文件 | 粒度 | 关键列 |
|---|---|---|
| `sim_users.csv` | 用户 | `act_30d / silence_days / interest_concentration / tenure_days / a_daily / y_void_window` |
| `sim_effects.csv` | 用户 × 臂 | `tau_struct`（结构 CATE）**/** `tau_ind`（个体真值）`/ cost / y_void_window / y_treated_window / increment / reward` |
| `sim_daily.csv` | 天 × 臂 | `events_population / void_population / increment_population` |
| `_manifest.json` | — | 版本 / 种子 / 参数快照 / 人口口径与指纹 / 输出行数与 sha256 / 双跑一致性 |

示例（离线默认分布，800 人 × 14 天）：召回的 population 平均奖励 ≈ **+1.1 事件/人**（42% 用户为正），推荐的 ≈ **−0.4**（约 5% 用户为正）——**这正是该死守的数据结论：在沉默为主的社区里，无差别推内容不如精准召回**；谁能把这两条臂的分界学准，谁就赢下策略。

## 8. 与下游的接口

| 下游 | 用法 |
|---|---|

## 9. 已知局限（诚实清单）

1. **无监督标签**：真值是模拟器给的因果量，不是真实世界观测——它的价值在"方法验证"，不在"业务数字"。
2. **域差**：校准锚点来自 Reddit 公开统计（gaming / truegaming），与任何单平台的分布存在域差；锚点只在"形态量级"上使用。
3. **负效应未建模**：打扰 / 取关 / 口碑损失除成本外无惩罚；奖励框架已留位，等有数据再进 v1。
4. **联合分布近似**：边缘分位数 + 秩耦合，非完整联合拟合。
5. **不模拟网络效应**：用户间零交互（社区生态、从众效应等不在 v0）。
6. **周留存分层未对齐**（见 §6）。
